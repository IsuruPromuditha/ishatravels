# 🌴 Paradise Island Sri Lanka — Travel & Tour Booking Platform

A full-stack web application designed for exploring Sri Lankan destinations, villas, and tour packages, complete with a dynamic booking workflow.

---

## 📌 Features

* **Interactive Hero Slideshow:** Automated hero background rotation showcasing top Sri Lankan landmarks.
* **Curated Tour Packages:** Detailed multi-day itineraries with day-by-day expandable breakdowns and image carousels.
* **Dynamic Booking Flow:** Direct redirection from package cards to a dedicated booking form with auto-filled package details (Title, Duration, Price, and ID).
* **Villa & Accommodation Directory:** Filterable listings for Sri Lankan coastal resorts, stays, and lodges.
* **REST API Architecture:** Node.js, Express, and PostgreSQL backend managing packages, itineraries, villas, and customer reservations.

---

## 🛠️ Tech Stack

### Frontend
* **Framework:** React.js
* **Routing:** React Router DOM (`v6`)
* **Styling:** Tailwind CSS

### Backend
* **Runtime:** Node.js
* **Framework:** Express.js (TypeScript)
* **Database:** PostgreSQL
